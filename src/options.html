Firefox: enable go/ once

If Firefox searches for your shortcut, make this one-time change:

  1. Type about:config in the address bar and continue past the warning.
  2. Search for browser.fixup.domainwhitelist.go.
  3. Select Boolean, click +, and ensure the value is true.

Now type go/docs directly. This setting applies only to the go hostname. Firefox requires you to change it manually; the extension cannot set it.

Also available: type go, press Space, then enter docs.
